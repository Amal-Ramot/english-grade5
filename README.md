# English Quest — אנגלית לכיתה ה׳

אתר תרגול אנגלית לילדים, מבוסס על דף העבודה "Grade 5 English Home Practice".
Next.js 15 + React 19 + Tailwind CSS 4 + Motion, מיוצא כאתר סטטי ל־GitHub Pages.

שישה משחקים: קריאת סיפור (עם תרגום מילים בלחיצה והקראה), בנק מילים, המילה הנכונה,
תרגום, משחק זוגות ו־am / is / are. בסיבוב הראשון מופיעות השאלות המקוריות מהדף, ובסיבובים
הבאים השאלות מתערבבות ומתווספות שאלות חדשות. כוכבים, נקודות ורצף ימים נשמרים בדפדפן.

```bash
npm install
npm run dev
```

הפריסה ל־Pages נעשית אוטומטית ב־`.github/workflows/deploy.yml`.
